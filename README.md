SiteCommit — dated 3D site history and its evidence desk. Node 22+: `npm ci && npm run dev` → http://127.0.0.1:4173; checks: `npm test`, `npm run verify`, `npm run build`; publish to the existing linked Vercel project with `vercel --prod` → [sitecommit.vercel.app](https://sitecommit.vercel.app).
