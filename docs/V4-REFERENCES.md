## Interpretation and licensing boundaries

Original photographs are real captures. SPZ models and renderer stills are derived reconstructions, not raw surveys or measurement certification. Reviewer stage tags remain authored assessments. Illustrative plans, sketches and quantities keep their existing labels. Camera synchronization makes model comparison easier to read; it does not remove registration, occlusion, coverage or reconstruction uncertainty. A camera path changes the viewing position, never construction geometry.

Dataset licenses and software licenses are separate: attribution for iVISION and Montijo must remain in product provenance and exports; MIT software notices for Spark/Three.js stay with distribution. Public visibility of a third-party viewer alone is not permission to extract its models. This build uses the independently hosted assets already covered by the recorded source terms.

## Repeatable limited-network check

After `npm run build`, run:

```sh
python scripts/throttled-preview.py --root dist --port 4184 --kbps 1600 --latency-ms 150
```

Open `http://127.0.0.1:4184/` in a fresh browser tab at 390px width. The stdlib server adds 150ms before each response and caps each response body to 1,600 decimal kilobits/s (200,000 bytes/s); it logs bytes and elapsed time. It sends no-store headers, serves SPZ as binary and rejects path traversal. Concurrent connections have independent caps, so this is **not** an aggregate 1.6Mbps mobile-radio simulation. External Google Fonts are outside this local profile. It imposes no CPU/GPU throttle and is not physical-handset testing. Record model-ready time, date scrubbing, compare, walkthrough, fallback, and interaction behavior separately rather than presenting network timing as FPS or device certification.
